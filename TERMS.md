# Terms of Service for Selective Auto Publisher

Effective date: 2026-07-03

Selective Auto Publisher, or SAP, is a Discord bot for selectively publishing messages from announcement channels.

By adding or using SAP in a Discord server, you agree to these terms.

## Use of the bot

SAP may be used to automatically publish messages that match configured rules.

Server administrators are responsible for how SAP is configured in their server, including:

* which channels SAP is allowed to process
* which bot user IDs are allowed
* which keywords are allowed
* which keywords are blocked
* which channel-specific filters are configured
* which audit channel is used
* which publish mode is active

## Message processing

SAP may check message content, embeds, authors, channel IDs, and configured filters to decide whether a message should be published or skipped.

Server administrators are responsible for ensuring that SAP is only used in channels where this processing is appropriate.

## Audit output

SAP may send audit messages to a configured audit channel.

Server administrators are responsible for choosing an appropriate audit channel and controlling who can view it.

## Permissions

SAP requires Discord permissions needed to read relevant channels, publish messages in announcement channels, use slash commands, and write audit messages when an audit channel is configured.

Do not grant SAP permissions that are not needed for your server setup.
